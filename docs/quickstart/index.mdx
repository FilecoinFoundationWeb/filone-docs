This guide walks you through creating an account, setting up credentials, and uploading your first object. Choose the path that fits your workflow.

## 1. Create your account

1. Go to [app.filone.com](https://app.filone.com) and sign up with your email, Google, or GitHub.
2. Verify your email address.
3. You're in. No credit card needed — your 30-day free trial starts automatically.

## 2. Create a bucket

From the dashboard, click **New bucket** to open the create form. Give the bucket a name (lowercase letters, numbers, and hyphens; unlike AWS S3, Fil One does **not** allow dots) and pick a region:

| Setting | Options | Notes |
|---------|---------|-------|
| Region | `eu-west-1` Europe (France) or `us-east-1` US East (Michigan) | Defaults to `eu-west-1`. Cannot be changed later. |
| Encryption | Always on | All data is encrypted at rest. Nothing to configure. |

Leave everything else at its default for your first bucket, and click **Create bucket**.

:::warning Some settings can only be chosen now
Versioning, Object Lock, and retention sit under **Advanced settings** on the create form, and can only be turned on when the bucket is created. Neither can be turned off later, and Object Lock can stop you deleting data you're paying for. Read [Versioning](/storage/versioning) and [Object Lock](/storage/object-lock) before you enable them on a bucket you plan to keep.
:::

## 3. Upload your first object

Choose your preferred method. The App requires no API key. For CLI and SDK access, open your new bucket and click **Create API key**, or go to **API Keys** in the left menu and click **Create new key**. You'll get two values:

- **Access Key ID** — identifies the key (safe to store in config)
- **Secret Access Key** — authenticates your requests (treat like a password)

:::note
Your secret key is shown once. Copy it and store it securely. If you lose it, rotate the key from its **⋯** menu in **API Keys** to get a new secret. See [API Keys](/app/api-keys#rotating-a-key).

A key also belongs to a single region, so create it in the same region as your bucket.
:::

The examples below use `eu-west-1`, the default region. For a bucket in `us-east-1`, use `https://s3.us-east-1.filonecontent.com` and region `us-east-1` instead.

<Tabs>
  <TabItem value="app-ui" label="App">
    1. Open your bucket from the dashboard.
    2. Click **Upload object**, select one or more files (or drag a whole folder in), then click **Upload** to start the transfer.
    3. Your objects appear in the file list once the upload completes.
    4. To download: click the download icon on the object's row, or open the object's detail page and use the **Download** button in the header.
  </TabItem>

  <TabItem value="aws-cli" label="AWS CLI">
    Create a `filone` profile so you don't overwrite your default AWS credentials. Requires [AWS CLI v2](/sdk/cli). The last command asks for your key's ID and secret: paste each when prompted, and press Enter at the other prompts to keep their values. It comes last so that pasting the whole block doesn't feed the other commands to the prompt as answers:

    ```bash
    aws configure set region eu-west-1 --profile filone
    aws configure set endpoint_url https://s3.eu-west-1.filonecontent.com --profile filone
    # Path-style is required: Fil One does not support virtual-hosted URLs
    aws configure set s3.addressing_style path --profile filone
    aws configure --profile filone
    ```

    Upload a file:

    ```bash
    echo "hello" > my-file.txt
    aws s3 cp my-file.txt s3://my-bucket/my-file.txt --profile filone
    ```

    Verify it's there:

    ```bash
    aws s3 ls s3://my-bucket/ --profile filone
    ```
  </TabItem>

  <TabItem value="python-boto3" label="Python (boto3)">
    Create `my-file.txt` first, for example with `echo "hello" > my-file.txt`.

    ```python
    import boto3
    from botocore.config import Config

    s3 = boto3.client(
        "s3",
        endpoint_url="https://s3.eu-west-1.filonecontent.com",
        aws_access_key_id="YOUR_ACCESS_KEY",
        aws_secret_access_key="YOUR_SECRET_KEY",
        region_name="eu-west-1",
        config=Config(signature_version="s3v4", s3={"addressing_style": "path"}),
    )

    # Upload a file
    s3.upload_file("my-file.txt", "my-bucket", "my-file.txt")

    # List objects to confirm
    response = s3.list_objects_v2(Bucket="my-bucket")
    for obj in response.get("Contents", []):
        print(obj["Key"], obj["Size"])
    ```
  </TabItem>

  <TabItem value="javascript-aws-sdk-v3" label="JavaScript (AWS SDK v3)">
    Save this as `upload.mjs` (it uses ES modules and top-level `await`), then run `node upload.mjs`:

    ```javascript
    import { S3Client, PutObjectCommand, ListObjectsV2Command } from "@aws-sdk/client-s3";
    import { readFileSync } from "fs";

    const client = new S3Client({
      endpoint: "https://s3.eu-west-1.filonecontent.com",
      region: "eu-west-1",
      forcePathStyle: true,
      // SDK v3.729+ adds checksums Fil One doesn't accept on presigned uploads
      requestChecksumCalculation: "WHEN_REQUIRED",
      responseChecksumValidation: "WHEN_REQUIRED",
      credentials: {
        accessKeyId: "YOUR_ACCESS_KEY",
        secretAccessKey: "YOUR_SECRET_KEY",
      },
    });

    // Upload a file
    await client.send(new PutObjectCommand({
      Bucket: "my-bucket",
      Key: "my-file.txt",
      Body: readFileSync("my-file.txt"),
    }));

    // List objects to confirm
    const { Contents } = await client.send(
      new ListObjectsV2Command({ Bucket: "my-bucket" })
    );
    Contents?.forEach((obj) => console.log(obj.Key, obj.Size));
    ```
  </TabItem>
