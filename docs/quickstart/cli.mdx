The [Quickstart](/quickstart?tool=cli) covers signup, the bucket and the API key, and uploads a first file with the AWS CLI. This page adds what the Quickstart skips: the profile as a config file, a profile per region, and creating a bucket from the CLI. For every other command, see [AWS CLI](/sdk/cli).

You need an API key in the same region as your bucket. To create one, open **API Keys** in the [console](https://app.filone.com) and click **Create new key**. The secret is shown once.

## 1. Install the AWS CLI

Use **AWS CLI v2**, version 2.13 or later, so the CLI reads `endpoint_url` from your profile:

```bash
brew install awscli
# or follow the official installer:
# https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html
```

## 2. Configure a profile

The `aws configure` commands in the Quickstart write these two files, and you can also edit them directly. A named profile keeps your default AWS credentials untouched, and you don't have to pass `--endpoint-url` on every command:

```ini
# ~/.aws/config
[profile filone]
endpoint_url = https://s3.eu-west-1.filonecontent.com
region = eu-west-1
s3 =
    addressing_style = path
```

```ini
# ~/.aws/credentials
[filone]
aws_access_key_id = YOUR_ACCESS_KEY
aws_secret_access_key = YOUR_SECRET_KEY
```

The `addressing_style = path` line is required. Fil One only supports path-style URLs, and the CLI otherwise defaults to virtual-hosted style, which fails.

:::note The endpoint depends on your bucket's region
The example above uses `eu-west-1`, the default region. The endpoint, the region and your access key must all match the region of the bucket you work with. If you use both regions, add a second profile:

```ini
# ~/.aws/config
[profile filone-us]
endpoint_url = https://s3.us-east-1.filonecontent.com
region = us-east-1
s3 =
    addressing_style = path
```

Then add a `[filone-us]` section with your `us-east-1` key to `~/.aws/credentials`, and choose the region with `--profile filone-us`.
:::

Check the profile before you use it:

```bash
aws s3 ls --profile filone
```

It lists the buckets in the key's region. If you get an error, see [Troubleshooting](/reference/errors#troubleshooting).

## 3. Create a bucket

Whether `CreateBucket` works through the S3 API depends on the region. It is **not** available in `eu-west-1`, the default region. There, create the bucket in the [Fil One console](https://app.filone.com): click **New bucket** on the dashboard, enter `my-bucket` (or your own name), and click **Create bucket**.

In `us-east-1` you can create a bucket from the CLI, with the `filone-us` profile and a key that has the `CreateBucket` permission. That permission isn't selected by default when you create a key:

```bash
aws s3 mb s3://my-bucket --profile filone-us
```

Versioning and Object Lock can only be turned on when you create the bucket in the console. See [Buckets](/storage/buckets).

## 4. Upload, list and download

The commands below use the `filone` profile (`eu-west-1`). For a bucket in `us-east-1`, use `--profile filone-us`.

```bash
echo "hello" > my-file.txt
aws s3 cp my-file.txt s3://my-bucket/ --profile filone
aws s3 ls s3://my-bucket/ --profile filone
aws s3 cp s3://my-bucket/my-file.txt ./downloaded.txt --profile filone
```

For syncing folders, deleting objects, presigned URLs and multipart uploads, see [AWS CLI](/sdk/cli).
